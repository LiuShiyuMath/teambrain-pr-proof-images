Team Videos · Feature #3

Your team is shipping.
Can you see it?

One command records the screen, one command uploads to centralized storage, one link replays it for your whole team. Three commands, no SaaS sign-up, no GDPR ticket.

$ screencapture -v ~/clip.mov # macOS native
$ teamagent video upload ~/clip.mov
# → link: http://collector/api/file?user=alice&id=...&ext=mov

What you actually see

Boss-grade dashboard. Not a debug log. Click into the collector and this is the page you land on — every teammate’s upload, inline playback, copy-to-share link.

/videos · 5 uploads from 5 teammates · live data from the digital-twin collector running on port 19200

One click, every upload

The list is chronological. Click any teammate to load their clip. SHA-256, container, capture timestamp, and the share link are right there.

@carol — Dark mode visual polish (MOV)
@alice — Checkout 500 repro (MP4)

Three commands. End of process.

Native OS recording. Single-shot HTTP upload. A share link that anyone with network reach can fetch. No queue setup, no S3 bucket policy, no Loom subscription.

1

Record

macOS screencapture -v. Linux ffmpeg -f x11grab. Windows ffmpeg -f gdigrab. Tools your team already has.

2

Upload

teamagent video upload <file>. One HTTP POST. mov / mp4 / webm / mkv. Returns a stable share link.

3

Share

Paste the link in Slack / a PR / a postmortem. Anyone with the URL gets the bytes with the right Content-Type. Recipients don’t install anything.
